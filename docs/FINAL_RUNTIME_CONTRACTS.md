# @connectingmatrix/chat final runtime contracts

This file is generated by the final process-monitor / project / nodes / workflow-AI / Giga-agents hardening pass.

## Ownership

- single chat system
- queryChat/queryChaat compatibility
- chat messages and modes
- slash routing
- attachments through drive/file
- browser-only debug sessions

## Public API contracts

- `Chat.getChats()`
- `Chat.getMessages(chatId,pagination)`
- `Chat.search(chatId,term)`
- `Chat.queryChat(chatId,options)`
- `Chat.queryChaat(chatId,options)`
- `Chat.registerSlashCommand(command,handler)`
- `Chat.createBrowserSession(options)`
- `Chat.queryBrowserSession(sessionId,message,options)`
- `Chat.clearBrowserSession(sessionId)`
- `Chat.attachFiles(chatId,files)`

## Routes / launcher

- `GET /chat/health`
- `POST /chat/query`
- `POST /chat/browser-session`
- `GET /chat/launcher`
